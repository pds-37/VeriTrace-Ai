# Field Test Companion — Backend & Hash-Linked Chain of Custody (Person C)

A high-performance, tamper-evident backend service built with **Python**, **FastAPI**, **Pydantic**, and **SQLite**. 

This service provides server-side digital evidence ingestion, offline-to-online synchronization with conflict protection, deterministic hash-linked chain-of-custody auditability, and standardized laboratory evidence package export.

---

## Key Features

1. **Hash-Linked Chain of Custody (Cryptographic Audit Trail)**:
   - Each evidence record is deterministically hashed using SHA-256 over its canonical payload and linked directly to the previous record's hash (`previous_record_hash`).
   - Genesis record links to a fixed 64-zero string (`0000...0000`).
   - Tampering with any stored record or broken sequence links is instantly detected by `/api/chain/verify` and `/api/records/{record_id}/verify`.
   - *Note: This is a deterministic cryptographic audit trail / chain of custody, not a blockchain.*

2. **Idempotent Sync & Conflict Protection**:
   - Accepts batches of offline records generated by the mobile application (`POST /api/sync`).
   - **Idempotency**: Repeatedly syncing the exact same record is safe and returns `already_synced` without duplicate insertion.
   - **Conflict Detection**: If an incoming record with an existing `record_id` contains divergent content (different image hash or sample ID), it returns `conflict` and **never silently overwrites** the server's evidence record.

3. **Standardized Lab-Handoff Evidence Package**:
   - `GET /api/export/{record_id}` produces a complete, structured JSON package for forensic handoff to confirmatory testing laboratories.
   - Prominently marked with: `"FIELD TEST RESULTS ARE PRESUMPTIVE ONLY AND DO NOT REPLACE LABORATORY CONFIRMATION."`

4. **Mobile Schema Interoperability**:
   - Fully compatible with Field Test Companion mobile client schemas (`snake_case` and `camelCase` field aliases).

## API Reference

### 1. Records Endpoints
- `POST /api/records`: Ingest a new field test evidence record.
- `GET /api/records`: List evidence records (query parameters: `limit`, `offset`, `order`).
- `GET /api/records/{record_id}`: Retrieve a single evidence record by ID.
- `GET /api/records/{record_id}/verify`: Verify single record payload integrity and chain linkage.

### 2. Chain of Custody Audit
- `GET /api/chain/verify`: Audits the entire chain sequentially from Genesis to Head. Returns detailed validity report, tampered IDs, and sequence status.

### 3. Synchronization
- `POST /api/sync`: Synchronizes a batch of offline field test records from mobile clients with conflict protection.

### 4. Evidence Export
- `GET /api/export/{record_id}`: Generates a JSON forensic evidence and lab-handoff package.

## Getting Started

### 1. Install Dependencies
```bash
cd backend
pip install -r requirements.txt
```

### 2. Start the Backend Server
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

- **Interactive Swagger Docs**: `http://localhost:8000/docs`
- **ReDoc Documentation**: `http://localhost:8000/redoc`
- **Health Check**: `http://localhost:8000/health`

### 3. Run Automated Tests
```bash
cd backend
pytest tests/ -v
```
